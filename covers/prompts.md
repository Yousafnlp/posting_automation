# Reel cover backgrounds: Gemini prompts

1. Open gemini.google.com and upload your photo (`~/Downloads/WhatsApp Image 2026-10-01 at 4.59.47 PM.jpeg`).
2. Paste one prompt. If your face changes, reply: *Keep my face identical to the photo, change nothing about my face.*
3. Save the image into `covers/backgrounds/` **named exactly like the reel**, e.g. `reel_02_motivation_trap.png`.
4. Tell Claude, or run `npm run covers` and then `npm run upload:thumbs`.

The cover text (added later, not by Gemini) is shown above each prompt and lives in `covers/texts.json`.
